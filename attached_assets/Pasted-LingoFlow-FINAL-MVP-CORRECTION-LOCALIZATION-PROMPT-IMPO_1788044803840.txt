============================================================
1. CORE PRODUCT CONCEPT
============================================================

LingoFlow is a language-learning application based on learning WORDS THROUGH SENTENCES and active practice.

The user chooses:

1. Native language
2. Target language
3. Daily learning goal

Then the user creates personal Word Sets containing at least 4 words.

Example:

Set name:
Travel

Words:

hotel
reservation
passport
luggage

The application stores these words and later uses them to create learning activities based on:

- Meaning
- Translation
- Listening
- Reading
- Writing
- Speaking
- Sentence recall
- Sentence usage
- Context variations
- Word forms
- Relevant tenses
- Spaced repetition

The goal is NOT to memorize isolated words.

The user must learn how to USE the words inside complete sentences.

============================================================
20. TENSES AND WORD FORMS
============================================================

Do not teach all tenses at once.

Introduce relevant forms gradually.

Example:

go

Present:

I go to work every day.

Past:

I went to work yesterday.

Future:

I will go tomorrow.

Present continuous:

I am going home.

Present perfect:

I have gone there before.

Do not force tense variations for words where tense is not relevant.

Track forms separately.

Example:

go
Present = strong
Past = weak
Future = strong

If the user repeatedly makes mistakes with the Past form:

Prioritize that form during future review.
